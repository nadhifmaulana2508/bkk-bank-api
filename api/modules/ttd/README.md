# Modul TTD

Modul TTD membungkus flow TTD yang sudah ada agar dapat digunakan oleh Monbis
dan Notaris melalui kontrak API yang konsisten.

Kemampuan awal:

- cek status TTD pegawai;
- proses signing;
- menyimpan document hash dan verification token;
- mengambil status verifikasi;
- mencatat audit.
