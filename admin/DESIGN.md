# SSO Control Plane design direction

- Identity: internal BKK control plane; quiet, operational, and trustworthy.
- Structure: the main decision is application lifecycle management, so the registry table is the primary surface. Metrics and hit activity support that decision instead of competing with it.
- Palette: neutral Zinc-like surfaces with black as the primary action and blue only for keyboard focus and text actions. No gradient or decorative glow.
- Typography: system sans for readable operations; monospace only for app codes, paths, and one-time secrets.
- Mood: precise and calm. Status is always written as text and never communicated by color alone.
- Dials: ENERGY 1, RHYTHM 2, MOTION 1.
